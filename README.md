## Contributing

Suggestions and pull requests are welcome. To add an entry:

- Choose **Blogs**, **Papers / Embodied AI**, or **Papers / World Models**.
- Include the full title, publication date, and original source link.
- For blogs, include the author or organization. For papers, add project and code links when available.
- For papers, briefly describe what improves and how feedback drives the update.
- Place the entry in chronological order, newest first. For work spanning both paper categories, use the category closest to its main contribution.
